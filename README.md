# Супер Метко Рън 🏃‍♂️🍄

Браузърна платформена игра в стила на *Super Mario Run*: Метко тича сам, ти само скачаш.

▶ **Играй:** https://me7ko-dev.github.io/super-metko-run/

## Два режима
На началния екран избираш със стрелките (или тап върху кутийката):

- **РЪН** — като Super Mario Run: Метко тича сам, ти само скачаш. Кестенко се прескача автоматично, ниските препятствия също.
- **КЛАСИКА** — ходиш напред и назад със стрелките, спираш когато искаш. Класически правила: Кестенко те наранява отстрани, трябва да го стъпчеш. +100 секунди време. Отделен рекорд.

## Управление
| Действие | Клавиатура | Телефон |
|---|---|---|
| Скок | `Space` / `↑` / `W` / `Z` | тап (РЪН) / бутон ▲ (КЛАСИКА) |
| По-висок скок | задръж | задръж пръста |
| Напред / назад (КЛАСИКА) | `←` `→` / `A` `D` | бутони ◀ ▶ долу вляво |
| Пауза | `P` / `Esc` | — |
| Звук вкл/изкл | `M` | — |

## Какво има
- 4 свята: **Зелена долина**, **Подземието**, **Залезни скали**, **Нощната крепост**
- Блокчета с „?“ (монети и **Силогъбка**, която те прави голям), тухли, тръби, стълби, ями, летящи платформи
- Врагове: **Кестенко** (стъпчи го или го прескочи автоматично), **Бодливко** (не се стъпква!), **Бръмчо** (лети), **Хапльо** (излиза от тръбите)
- Авто-прескачане на ниски препятствия, контролна точка по средата на нивото, флаг с бонус за височина, таймер, рекорд
- Цялата графика и звук са генерирани с код (Canvas + WebAudio) — без външни картинки и аудио файлове

## На iPhone (приложение)
Свържи телефона с Mac-а (кабел или същата Wi-Fi мрежа), отключи го и пусни:
```
bash mobile/ios-install.sh
```
С безплатен Apple акаунт приложението работи 7 дни — после пак пусни командата (рекордите се пазят).
На телефона: бутон **II** горе вдясно = пауза; в паузата — ЗВУК вкл./изкл., докосване = продължаване.

## Стартиране локално
Просто отвори `index.html` в браузър. Няма build стъпка.

Тестове (глобалния Playwright): `node test/smoke.mjs`, `node test/levels.mjs run`, `node test/levels.mjs classic`.

Шрифт: *Press Start 2P* от CodeMan38 (SIL Open Font License), в папка `fonts/`.
