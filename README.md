# Супер Метко Рън 🏃‍♂️🍄

Браузърна платформена игра в стила на *Super Mario Run*: Метко тича сам, ти само скачаш.

▶ **Играй:** https://me7ko-dev.github.io/super-metko-run/

## Управление
| Действие | Клавиатура | Телефон |
|---|---|---|
| Скок | `Space` / `↑` / `W` / `Z` | тап |
| По-висок скок | задръж | задръж пръста |
| Пауза | `P` / `Esc` | — |
| Звук вкл/изкл | `M` | — |

## Какво има
- 4 свята: **Зелена долина**, **Подземието**, **Залезни скали**, **Нощната крепост**
- Блокчета с „?“ (монети и **Силогъбка**, която те прави голям), тухли, тръби, стълби, ями, летящи платформи
- Врагове: **Кестенко** (стъпчи го или го прескочи автоматично), **Бодливко** (не се стъпква!), **Бръмчо** (лети), **Хапльо** (излиза от тръбите)
- Авто-прескачане на ниски препятствия, контролна точка по средата на нивото, флаг с бонус за височина, таймер, рекорд
- Цялата графика и звук са генерирани с код (Canvas + WebAudio) — без външни картинки и аудио файлове

## Стартиране локално
Просто отвори `index.html` в браузър. Няма build стъпка.

Тест: `node test/smoke.mjs` (ползва глобалния Playwright).
